# Skystore — Интернет-магазин цифровых продуктов и плагинов

Веб-приложение на базе фреймворка **Django**, представляющее собой платформу для хранения и продажи плагинов, утилит, телеграм-ботов и примеров кода.

## Функциональность

* **Главная страница (`/`):** Витрина с описанием сервиса и карточкой цифрового продукта.
* **Страница контактов (`/contacts/`):** Реквизиты компании и форма обратной связи с защитой от CSRF-атак (`{% csrf_token %}`).
* **Каталог товаров и административная панель (`/admin/`):** Управление категориями (`Category`) и продуктами (`Product`) с поддержкой фильтрации, поиска и загрузки изображений.
* **Автоматическое наполнение БД:** Наличие фикстур и кастомной management-команды для быстрого сброса и заполнения базы тестовыми данными.
* **Адаптивный интерфейс:** Верстка выполнена с использованием локальных файлов **Bootstrap 5** и встроенной системы управления статикой Django (`{% load static %}`).

## Технологический стек

* **Python** 3.12+
* **Django** 5.x / 6.x
* **PostgreSQL** (СУБД) + `psycopg2-binary`
* **Pillow** (работа с изображениями и медиафайлами)
* **python-dotenv** (управление переменными окружения)
* **IPython** (интерактивная оболочка Django Shell)
* **HTML5 / CSS3 / Bootstrap 5**

## Установка и запуск проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd Django-2
   ```

2. **Создайте и активируйте виртуальное окружение:**
   * Для Linux / macOS:
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```
   * Для Windows:
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте базу данных и переменные окружения:**
   * Создайте пустую базу данных в PostgreSQL (например, `catalog_db`).
   * Скопируйте шаблон `.env.sample` в файл `.env` и заполните своими данными:
     ```bash
     cp .env.sample .env
     ```
   * Пример содержимого `.env`:
     ```env
     DB_NAME=catalog_db
     DB_USER=postgres
     DB_PASSWORD=ваш_пароль
     DB_HOST=localhost
     DB_PORT=5432
     ```

5. **Примените миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

6. **Загрузите тестовые данные в базу:**
   * С помощью кастомной команды (очищает старые записи и загружает фикстуры):
     ```bash
     python manage.py fill_db
     ```
   * Или вручную через стандартную команду `loaddata`:
     ```bash
     python manage.py loaddata fixtures/categories.json
     python manage.py loaddata fixtures/products.json
     ```

7. **Создайте суперпользователя (для доступа в админку):**
   ```bash
   python manage.py createsuperuser
   ```

8. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver
   ```

9. **Откройте проект в браузере:**
   * Главная страница: [http://127.0.0](http://127.0.0)
   * Страница контактов: [http://127.0.0contacts/](http://127.0.0contacts/)
   * Панель администратора: [http://127.0.0admin/](http://127.0.0admin/)

```text
├── catalog/                    # Приложение каталога
│   ├── management/
│   │   └── commands/

│   ├── migrations/             # Файлы миграций базы данных
│   ├── templates/
│   │   └── catalog/
│   │       ├── home.html       # Главная страница
│   │       └── contacts.html   # Страница контактов
│   ├── admin.py                # Настройка отображения моделей в админ-панели
│   ├── models.py               # Модели Category и Product
│   ├── urls.py                 # Маршруты приложения
│   └── views.py                # Контроллеры
├── fixtures/                   # Фикстуры для наполнения БД
│   ├── categories.json
│   └── products.json
├── media/                      # Загружаемые пользователем медиафайлы (игнорируется Git)
├── static/                     # Локальные статические файлы (Bootstrap CSS и JS)
│   ├── css/
│   └── js/
├── .env                        # Переменные окружения с паролями (игнорируется Git)
├── .env.sample                 # Шаблон файла переменных окружения
├── .gitignore                  # Список исключений для Git
├── manage.py                   # Утилита управления проектом Django
├── requirements.txt            # Список зависимостей проекта
└── README.md                   # Документация проекта
```
