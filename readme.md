# Skystore — Интернет-магазин цифровых продуктов и плагинов

Веб-приложение на базе фреймворка **Django**, представляющее собой платформу для хранения и продажи плагинов, утилит, телеграм-ботов и примеров кода.

## Функциональность

* **Главная страница (`/`):** Витрина с описанием сервиса и карточкой цифрового продукта.
* **Страница контактов (`/contacts/`):** Реквизиты компании и форма обратной связи с защитой от CSRF-атак (`{% csrf_token %}`).
* **Адаптивный интерфейс:** Верстка выполнена с использованием локальных файлов **Bootstrap 5** и встроенной системы управления статикой Django (`{% load static %}`).

## Технологический стек

* **Python** 3.12+
* **Django** 5.x / 6.x
* **HTML5 / CSS3 / Bootstrap 5**

## Установка и запуск проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd Django-2
   ```

2. **Создайте и активируйте виртуальное окружение:**
   * Для Linux / macOS:
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```
   * Для Windows:
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Если файла `requirements.txt` еще нет, установите Django вручную: `pip install django`)*

4. **Выполните миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

5. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver
   ```

6. **Откройте проект в браузере:**
   * Главная страница: [http://127.0.0](http://127.0.0)
   * Страница контактов: [http://127.0.0contacts/](http://127.0.0contacts/)
